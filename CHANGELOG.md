# Changelog

## 0.5.4 to 0.5.2 (2026-10-17)

- README opening and script description rewritten to cover the full feature set, starting with each channel's most used emotes and the privacy and resource numbers.

## 0.5.1 (2026-10-17)

- Only the 10 most recently visited channels keep their emote lists in memory during a session.
- The message preview no longer redraws when the text hasn't changed.
- Picker sections now follow an animation setting changed during a search.
- With every service turned off, the picker says so instead of "Emotes are still loading."

## 0.5.0 (2026-10-17)

- Tab completion strip: the matches above the chat box while cycling, with the current one outlined and its position.
- Message preview: your message with emotes above the chat box while you type. Can be turned off in the settings.
- "New in this channel": 7TV emotes the channel added in the last 14 days, in the picker. The tooltip shows when an emote was added.

## 0.4.0 (2026-10-17)

- Settings panel in the picker (gear button).
- Animated emotes: Auto, Always, On hover or Never. Still versions download much less.
- Emote size in chat: Small, Normal or Large.
- BetterTTV, FrankerFaceZ and 7TV can each be turned off; a service that is off is not contacted.
- Collapse repeated emotes into one with a count (off by default).

## 0.3.1 (2026-10-16)

- Favourite emotes from the picker with the star in each emote's corner.

## 0.3.0 (2026-10-15)

- Click an emote in chat to favourite or hide it. Hidden emotes show as their name; click the name to show the emote again.
- The picker opens on Favourites and "Popular here", the emotes this channel's chat uses most.
- Hide mode in the picker.
- Search and Tab completion rank favourites and popular emotes higher.

## 0.2.1 (2026-10-15)

- Picker button lines up with Twitch's buttons in Safari.
- Picker emotes load in Safari.

## 0.2.0 (2026-10-15)

- Tab completion for emote names.
- Emote picker with search.

## 0.1.3 to 0.1.1 (2026-10-15)

- Instant hover tooltip with a larger preview, the emote's name and service.
- Declares `@inject-into content` for the Userscripts app.

## 0.1.0 (2026-10-15)

- BetterTTV, FrankerFaceZ and 7TV emotes in Twitch chat, including zero-width emotes.
